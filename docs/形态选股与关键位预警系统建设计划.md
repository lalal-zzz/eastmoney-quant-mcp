# 形态选股与关键位预警系统建设计划

版本：v1.2；编制日期：2026-09-17。修订主题：四层职责、锚点选择、方向性位置阶段、独立 Projection 与证据去重。

本文是实施计划，尚未实现其中新增功能，也未启动行情订阅或外部通知。

实施状态（2026-09-17）：已开始代码实施。第一批已完成多尺度确认 Pivot/Leg、趋势线两点确定三点确认、固定宽度平行通道、横向区间、非对称 W/M 骨架、方向性回撤/投射、共振依赖去重、区域预警状态机、SQLite 预警状态/事件持久化，以及 `get_key_levels`/图表对统一结构结果的兼容接入。波浪解析器按当前决定暂不实现；后台轮询 worker、分钟/小时历史持久化、全市场新结构扫描器、订阅管理和外部通知仍待后续阶段，不能据此声称实时预警系统已经上线。

## 1. 目标与范围

建设可解释、可追溯、可回放的形态选股和关键位置预警系统。用户能够回答：当前属于什么结构、哪个周期形成、重要位置在哪里、正在接近还是已经确认、什么情况下失效，以及历史相同规则的表现如何。

优先级：趋势线、上升/下降/横向通道、双向斐波那契关键位、非对称 W/M、多周期选股与预警；波浪候选分析在共同基础完成后接入。

首期范围为 A 股股票与具备数据的板块；股票默认日线全市场初筛，60 分钟线对候选和关注池精查，周线提供大背景。30/15 分钟作为可选扩展。周期和波段级别独立建模，不规定“小时五浪等于日线一浪”。

输出包含候选池、确认池、风险池、结构图、关键位清单、预警历史和研究报告。首期实现本地 CLI、MCP、报告及本地预警收件箱；管理页面属于后续交付。自动下单不在本计划范围内。

核心架构原则：先建立长期 Price Structure Tree，再在结构树上运行 Elliott Wave Parser。Parser 可以修改解释，不能修改底层价格结构证据。

波浪级别不与固定时间周期绑定。周线、日线、小时线只是观测分辨率，不直接等价于 Primary、Intermediate、Minor 等波浪级别。级别由父子关系、相对幅度、持续时间和结构完整性共同评估，允许暂未确定。

```text
OHLC → 多尺度 Pivot → Leg → Segment → Structure / Price Structure Tree
                                         ├─ 趋势线、通道、区间、W/M
                                         ├─ 方向性 Fibonacci 与位置区域
                                         │        ↓
                                         │   Setup → 价格事件 Trigger → 选股/预警
                                         └─ Elliott Wave Parser
                                                  ↓
                                           WaveHypothesis 集合 → Context
```

观测结构层保存可复现的价格关系、规则识别结果和来源；位置层描述相对波段的位置；解释层保存可能的长期运动阶段。趋势线、W/M 等仍取决于识别尺度和规则，并非无条件真理；Fibonacci 是按锚点计算的位置，不是已被证明的支撑。解释层只读指定版本的结构树，不能为凑浪移动锚点、删除矛盾证据或修改预警触发事实。

正式划分四层；层号代表职责，不代表必须依次通过的流水线：

| 层 | 职责 | 典型输出 |
|---|---|---|
| Layer 1 — Observation | 价格及版本化结构识别 | Pivot、Leg、Segment、Trend/Range、Channel、W/M |
| Layer 2 — Position | 相对位置、投射与区域 | FibRetracement、Projection、Key Levels、Confluence |
| Layer 3 — Interpretation | 对已知结构的候选解释 | Wave、后续可扩展的 Regime/Scenario |
| Layer 4 — Event | 比较时序状态并记录变化 | Touch、Breakout、Retest、Reaction、Failure |

Event 可直接消费 Observation/Position，不必经过 Interpretation。“第 2 浪可能结束”属于解释，“0.618 被触及”属于位置上的事件，“小时 W 颈线突破”属于观测结构上的事件。解释修订可以独立记录，但不能变成价格确认事件。

单向依赖约束：Wave Parser 可以读取 Fibonacci 证据；Fibonacci 引擎绝不能依赖 Wave 标签生成锚点、区域或基础评分。禁止“Fib 推导 Wave，再由该 Wave 给同一 Fib 加分”的循环。

实施重心收敛为 Pivot、Leg、Segment、Trend/Range、Projection 五类基础能力。Projection 是独立位置计算基础；目标达到后形成的等幅运动观测另行记录。暂不扩展更多形态名称。

## 3. 产品工作流

1. 检查日线、小时线和板块数据状态，先更新已有数据库；空库或不足时才补历史。
2. 扫描日线与已完成周线，发现趋势、通道、区间和形态；形成全量结果与可配置候选池。
3. 对候选池、关注池和用户录入持仓池补充小时结构；持仓池不因排名下降退出风险监控。
4. 生成关键位，包括趋势线/通道边界、水平支撑压力、W/M 颈线和斐波那契区域。
5. 按实际可用行情频率检查接近、触及和穿越；闭合 K 线确认突破、回踩或失效。
6. 写入预警收件箱，展示原因、数据时间、价格坐标、规则和证据图。
7. 收盘归档，更新候选状态、预警后验表现和系统健康报告。

“收盘扫描”和“持续监控”是两种显式运行模式；单次 MCP 查询不会自动开启后台进程。

## 4. 数据与时间基础

### 4.1 统一 K 线

规范字段：市场、标的、周期、交易时区、开始/结束时间、OHLCV、金额、来源、复权口径、是否闭合、到达时间与数据版本。缺失值不得伪装成 0。

- 使用交易日历和交易时段定义分桶，正确处理午间休市、节假日和跨周；验证供应商小时线的标签含义。
- 日/周/月结构确认仅使用已闭合 K 线。未完成周期只能生成明确标记的预览。
- 历史前复权价格可能随除权事件改变；保存原始价格/复权因子或可重建版本，避免用当前复权结果覆盖当时证据。
- 实时报价与复权关键位比较前必须转换到同一价格坐标；预警同时保存计算价格和可读报价口径。
- 结构分析与模拟成交分别保留所用价格口径。多供应商切换前检查时间、单位、复权和异常跳变。

### 4.2 覆盖和取数

- 日线覆盖全市场；长历史按结构需要向前扩展，不把 320 根当作所有结构的统一充分条件。
- 小时线优先服务候选和关注池，按可获取历史逐步积累；探测实际历史上限，禁止从日线伪造小时子浪。
- 日线可分析、小时线不足时保留日线结果，并标记 `lower_timeframe_unverified`。
- 对板块单独记录各周期可用性；不存在的数据不通过股票数据源拼造。
- 复用网络封装、限速、退避、熔断、缓存和断点续传；不反复全量初始化。
- 分周期统计符合条件标的数、成功数、足够历史数、最新闭合 K 线和缺口；K 线覆盖不足 95% 不声称全市场完成。

### 4.3 波浪历史范围与分层压缩

- 波浪完整分析范围不得固定为最近 320/500/1000 根。首次分析优先读取标的可获得的长期日/周历史，记录最早可用日期、已读范围、缺口和读取进度。
- 数据按页读取并可中断恢复；计算预算限制本轮工作量，不裁定一浪最长只能持续多少天。尚未读完时返回 `history_incomplete`，不宣称长期解释完整。
- 先用粗尺度 major pivots 压缩长期历史，再构建 Leg、Segment 和结构树；仅对需要验证的时间段加载更细分辨率。
- 示例流程可为“约 5000 根日线 → 数百拐点 → 数十重要 Leg → 更少的高层 Segment → 多个整树假设”。数量仅示意，不是固定目标或必须删除到的数量。
- 压缩节点保留原始数据引用、子节点、极值、起止时间、确认时间、摘要指标和版本，可按需展开；摘要不得抹去硬规则校验所需的极值。
- 老历史通常读取结构摘要与缓存树，不每次逐根重算；价格修正、复权变化、规则版本变化时沿依赖关系标记受影响节点并重建。
- 粗数据无法证明内部浪型时保持 `unverified`；细历史不可得则保留未知。历史不足不能靠分辨率插值制造子结构。
- 更早历史在当前才补到时，可形成新的当前解释；其 `available_at` 必须是实际到达时间。过去 as-of 的在线快照不被覆盖，使用补齐历史的事后研究应单列为新数据版本。

## 5. 统一结构模型与多尺度拐点

建议增加 `strategies/structure/` 包。一个结构可被图表、选股、预警与回测共同读取。

核心对象：

| 对象 | 必需内容 |
|---|---|
| `Pivot` | ID、周期、尺度、类型、价格、发生时间、确认时间、数据版本 |
| `Leg` | 起止 Pivot、方向、价格变化、持续时间、ATR 标准化幅度、量能特征、确认状态 |
| `Segment` | 有序 Leg/子 Segment 引用、尺度、边界、极值、持续时间、聚合规则、确认时间 |
| `Structure` | ID、版本、方向、类型、锚点、状态、父子关系、形成/确认/失效时间 |
| `PriceStructureTree` | 根节点、结构节点/边、覆盖区间、as-of、来源及聚合规则版本 |
| `FibAnchorCandidate` | 锚点引用、anchor_source、anchor_scale、anchor_rank、确认/可用时间、来源谱系、排序依据 |
| `FibonacciStructure` | 公共身份与版本、方向、尺度、锚点候选引用、phase、可用性；严格区分 retracement/projection 子类型 |
| `FibRetracement` | A/B、current_price、retracement_ratio、position_ratio、phase；不需要 C |
| `ProjectionStructure / FibProjection` | A/B/C、目标倍率列表、current_price、projection_ratio、C 确认状态；FibProjection 使用配置比例集 |
| `FibZone` | 所属 FibonacciStructure、比例、中心价、上下界、容差依据、状态与触碰 episode |
| `EvidenceFamily` | family、来源结构/锚点、dependency_group、derived_from、相关性处理与有效权重 |
| `ConfluenceZone` | price_zone、来源集合、去重后证据组及分项、有效区间；可空的研究用 time_window |
| `WaveNode` | id、parent_id、children、degree、label、起止引用、status、rule_validity、score、invalidation、alternatives |
| `WaveHypothesis` | hypothesis_id、完整树/root、基础结构树版本、as-of、有效性、匹配分、未知节点、失效条件、修订来源 |
| `KeyLevel` | 来源结构、类型、坐标系、价格区域或动态函数、有效区间、生成时间 |
| `SignalEvent` | 结构/关键位、事件类型、触发时间、当时证据、规则版本 |
| `AnalysisSnapshot` | as-of、数据水位、结构集合、配置指纹、引擎版本 |
| `AlertDelivery` | 事件、订阅规则、渠道、投递状态、去重键、重试信息 |

结构 ID 根据不可变身份生成，不包含每次变化的分数；状态更新产生新 revision。重新选择锚点产生新结构，并记录替代关系。事件只追加，错误修正也用新记录表达。

多尺度采用独立参数组：以不同反转幅度/ATR 阈值和确认窗口生成细、中、粗波段。各尺度边界条件和最小波幅有明确配置。Pivot 先组成上涨/下跌 Leg，连续 Leg 按明确规则聚合为 Segment，再构建长期父子结构；不直接将最后六个 Pivot 标为完整数浪。

结构树中的父节点覆盖子节点时间区间，子节点有序且不得循环引用；同一节点内的结构分解不能任意重叠。不同尺度或分段方案可以产生不同树版本，并引用共享的不可变节点。事实树不需要 Elliott 标签才能成立；重新数浪不修改事实树。

WaveNode 的 parent_id/children 在所属 hypothesis 内解析；degree 保存相对层级和判定依据，命名级别可以未知。alternatives 是到替代节点/假设的引用，不把多个互斥子树拼成一套合法 count。每个 WaveHypothesis 表达一整棵解释树，可包含未分类子节点；整树分数不能掩盖子节点违反硬规则。

固定时间长度不作为通用形态定义；保留最小独立波动要求、单批读取/计算预算、候选数上限和过期策略，避免枚举爆炸。预算耗尽要报告 `search_incomplete` 并支持继续，不悄悄截断长期结构。过期表示不再监控，不等于形态失败。

不可变历史快照与最新 zigzag 分开：更极端的同类点可更新当前候选，但不能改写过去已经触发的事件。

## 6. 趋势线

采用用户指定口径：两点确定，三点确认。

1. 同尺度两个已确认的抬高低点建立上升支撑候选；两个降低高点建立下降压力候选。
2. 第三个独立触点必须位于第二锚点之后，并接近原线；获得规定幅度的反应或拐点确认后，才能进入 confirmed。
3. 触点发生时间与确认时间分开。连续贴线的一簇 K 线算一次，需有离开后再次进入或独立波段证据。
4. 不为迁就第三点修改原锚点；重选锚点创建新 ID。
5. 检查锚点之间和其后的穿越程度，排除明显穿过价格主体的线；影线容差、收盘破位分别配置。
6. 保存触点、跨度、ATR 标准化误差、穿越次数、距离、确认等级、当前有效性；按评分和相似性去重展示。
7. 趋势线只在局部有效窗口内保持斜率。默认限制锚点跨度和第二锚点后的延伸长度（当前实现默认 120 根该周期 K 线）；超过任一上限后，不再继续绘制斜线，而是保留原线证据并生成 `horizontal_level`，作为支撑/压力位跟踪。
8. 每个交易日按 `as_of` 截止重算；当天尚未出现或尚未确认的触点不能用于当天的趋势线。昨日的确认状态作为历史快照保留，今日出现新触点时只新增或更新后续状态。

线性坐标使用 `p(t)=p1+(p2-p1)*(t-t1)/(t2-t1)`，t 是该周期交易 K 线序号。预留对数价格坐标处理长跨度结构；每条线绑定坐标系，不能跨坐标直接比较斜率。

状态：candidate → confirmed → broken/converted；broken 后可跟踪 retest 和角色转换。converted 表示斜率关系已过期，关联对象按水平支撑/压力位处理，并保留原线锚点、触点与生命周期事实。

盘中穿越只是事件，不能直接视作确认失效。默认确认依据闭合 K 线，具体 ATR 缓冲和连续根数通过版本化规则设定。

## 7. 上升、下降和横向通道

### 7.1 斜向平行通道

- 在既定坐标系中，以主趋势线为一侧，用对侧已确认极值确定平行边界。
- 主线有效、对侧有独立重复触碰后确认通道；明确输出两侧各自证据，不能将单侧三点等同于双侧确认。
- 输出上下轨、中线、宽度、宽度/ATR、价格在通道内的位置、触轨与越轨事件。
- 固定通道的偏移量；新极值如需改变宽度，创建新候选，避免通道随每次突破自动扩大。
- 通道必须标注构造来源：`independent_trendlines` 表示上下边界都是独立确认的趋势线；`translated` 表示一条已确认主线按固定偏移平移到另一侧，并且另一侧必须有独立极值测试。不能用未经确认的第二条线或动态追价宽度冒充通道。
- 收敛/扩张结构不硬塞成平行通道，标记未覆盖结构；三角形与楔形可作为后续扩展。

### 7.2 横向通道/箱体

- 同尺度高点聚集形成上沿区，低点聚集形成下沿区；需上下沿各有独立测试和中间离开边缘的证据。
- 使用聚类容差、相对宽度、ATR 标准化漂移和价格停留比例判断横向，不能只看屏幕视觉角度。
- 保留上下沿区域、中轴、区间形成时间、触碰序列、内部小结构。
- 明确区间内波动、上破、下破、回踩/反抽、假突破和重新进入区间。
- 后续扩大或移动箱体形成新版本/新候选；不能修改历史边界来消除已经发生的突破。

## 8. W/M：非对称、嵌套与状态跟踪

W 使用低—高—低骨架，M 使用高—低—高骨架。骨架允许来自较粗尺度，内部可含多个小拐点。候选发现后持续跟踪，不因最新三个点改变就遗忘原结构。

### 8.1 形态变体

- W：平底、右底抬高、右底轻微下探后收回、宽右底、右侧横盘、复合右底。
- M：平顶、右顶降低、右顶轻微越过后回落、宽右顶、右侧整理、复合右顶。
- 两侧时长比例是描述与回测分层字段，不是必须接近 1 的硬规则。
- 记录 `left_duration`、`right_duration`、总跨度、两端价差/ATR、颈线高度、前置趋势和嵌套关系。
- “右边更长”作为用户关注的形态类别支持，不预先认定它在全市场占多数或表现更好。
- 轻微越界变体要求幅度可控并出现收回证据；明显超出结构边界则失效，不能无限放宽。

### 8.2 颈线和状态

基础双底以中间高点作为水平颈线；基础双顶以中间低点作为水平颈线。单个中间点不能确定倾斜颈线。复杂结构若有多个可用颈部锚点，再单独定义斜颈线变体。

W：forming → right_bottom_confirmed → neckline_breakout → retest_holding；任一阶段均可按规则转 failed/expired。

M：forming → right_top_confirmed → neckline_breakdown → retest_rejected；同时保留颈线守住反弹这一独立结果。

几何相似、结构确认、可交易条件分开。右底形成不等于突破颈线；顶部风险可以早于确认破位。形态量度目标仅作为参考区域，不能作为承诺收益。

## 9. 方向性 Fibonacci 回撤、扩展与多结构共振区

Fibonacci 是相对位置框架，回答当前价格相对于已确认波段走到哪里。FibonacciStructure 使用严格区分的 retracement/projection 子类型，共享方向、尺度、版本和来源；回撤只需 A/B，投射必须具有 A/B/C。current_price 是行情观测，绝不兼任 C。C 是位于 B 之后的回撤/反弹端点引用，未确认时只能生成 provisional 投射。

### 9.1 四类位置计算

| 类别 | 定义 | 输出 |
|---|---|---|
| 上涨波段回撤 | L→H 后 `H-r*(H-L)` | 向下回撤区与原低点边界 |
| 下跌波段反弹 | H→L 后 `L+r*(H-L)` | 向上反弹区与原高点边界 |
| 趋势延伸目标 | A→B 后调整到 C，`C+r*(B-A)` | 按 B-A 符号生成上涨/下跌扩展区 |
| 多段共振 | 不同尺度/周期的回撤或扩展区域重叠 | 各锚点、比例与独立证据来源 |

回撤比例初始包含 0.236、0.382、0.5、0.618、0.786、1.0；0.5 标注为常用回撤比例。扩展初始包含 1.0、1.272、1.618、2.0、2.618；列表可配置。明确区分“回撤 1.0”和“扩展 1.0”的模式。

相对回撤比例可统一为 `r_now=(B-current_price)/(B-A)`，A/B 同价时不计算。输出落在哪两个比例之间、是否越界、向上/向下接近和当前路径。比例不应截断到 [0,1]，否则会隐藏延伸或完全回撤。

### 9.1.1 回撤、相对位置与投射的字段契约

- `FibRetracement(A,B)`：`retracement_ratio=(B-P)/(B-A)`；`position_ratio=(P-A)/(B-A)`，两者相加为 1。
- `ProjectionStructure(A,B,C)`：目标 `D=C+k*(B-A)`；当前 `projection_ratio=(P-C)/(B-A)`。C 不得缺失，未确认 C 必须标明预览；确认投射要求 C 已确认且 A、B、C 时间有序。
- `FibProjection` 是上述 Projection 使用指定倍率集合的子类型，不另造一套公式。输出目标倍率 `target_multiple` 与当前达到的 `projection_ratio`，不使用无基准说明的 extension_ratio。
- 校验 A/B 非同价、价格/复权口径一致、锚点截至 as-of 已可用；active/provisional/invalid 等可用性与 phase 分开。

例如 A=10、B=20、P=15，回撤比例为 0.5。若 C=15 已确认且 P=21，则 position_ratio=1.1、retracement_ratio=-0.1、projection_ratio=0.6。UI 优先显示“原方向恢复，已越过 B；相对 A 走到 1.1 倍”，从 C 投射的 1.0 目标为 25，不能把 21 同时称为 C 起算的 1.1 扩展。底层保留未截断数值供审计。

### 9.1.2 当前运动阶段 phase

phase 描述相对固定 A/B 的路径，不是 Elliott 浪型。`impulse` 在此仅指原方向推进，不表示已识别出 Elliott 五浪。

| phase | 规则语义 |
|---|---|
| impulse | 原方向推进或 B 刚确认，尚无达到规则阈值的逆向调整；未确认 B 仅预览 |
| retracing | B 后出现达到最小幅度的逆向调整 |
| retracement_confirming | 调整后出现规则定义的反应，正在确认 C 或恢复条件 |
| resumed | 已有调整过程，随后满足原方向恢复条件；默认以闭合价格越过 B 加缓冲确认 |
| over_retraced | 回撤越过 A 并满足缓冲/闭合条件，即完整回撤边界被越过 |

状态必须根据路径计算，不能只由当前 ratio 推断；resumed 后再次回撤可进入新 episode。未达到确认条件时保留前状态并附 pending_event，跳空允许跨状态。phase、区域 touched/broken 和锚点有效性分别保存。缺历史无法判断运动过程时返回 phase_unknown；阶段切换阈值和缓冲必须版本化。

### 9.1.3 锚点选择、排序与生命周期

先生成 FibAnchorCandidate，再决定哪些波段进入计算/展示：

1. 从 confirmed Leg、confirmed Segment、通道内已确认 swing、满足跨度/幅度与顺序条件的 major pivot pair 取候选。
2. 每个候选保存 anchor_source、anchor_scale、观测周期、anchor_rank、确认/可用时间、版本与来源谱系。A/B 取有证据的结构边界，不能任意配对所有高低点。
3. 排序考虑结构显著性、幅度/ATR、历史完整性、时效性、结构仍否有效及冗余程度；固定配置下确定性排序，输出分项。不能因价格恰巧贴近 0.618 而事后挑锚点。
4. 小时、日线、长期候选同时保留；限制每尺度展示数量，不让最近小波段挤掉长期锚点。接口回答必须标明“哪个尺度、哪个 A→B 的 0.618”。
5. WaveNode 只能引用已经存在的候选或提供解释关联；不得作为 Fibonacci 引擎必需输入，也不得修改锚点、资格或基础排序。
6. 新 B/C 极值未确认时创建预览，确认后生成新身份/关联版本；旧实例按 active、superseded、invalidated、archived 管理。替代不等于失效，旧长期区域仍有效时可继续观察。
7. 活跃候选数量受预算控制；退出展示/监控需记录冗余、过期或明确失效原因。已触发事件所用旧锚点及区域永久保持可追溯，不被新锚点覆盖。

### 9.1.4 Measured Move 与独立 Projection

等幅投射 `D=C+(B-A)` 是 Projection 的 k=1.0 基础能力，无需 Wave 或 Fibonacci 标签即可运行。k=1.272、1.618、2.0、2.618 使用同一有符号公式生成更远目标；上涨与下跌镜像处理。

投射目标属于 Position，不表示 CD 已经发生。只有未来 D 的可用价格证据出现后，才可记录 AB≈CD 的观测/完成事件，并注明 ATR/相对幅度误差与确认时间。k=1.0 measured move 与 FibProjection 1.0 同锚点时是同一证据，不能重复加分。时间等长不是默认要求。

0.618 不永久等于支撑。上涨回撤与下跌反弹的潜在作用不同，穿越后可能出现角色变化。回撤达到 1.0 表示回到 A；触及或穿越原点应依据相应结构的确认规则判断失效，不能把瞬间触价自动等同于所有趋势失效。历史 A→B 波段本身仍作为历史证据保留。

### 9.2 Fibonacci Zone 与状态

每个比例生成 `fib_price ± tolerance` 的区域。容差配置结合 ATR、最小价格跳动与波段规模，示例可从 `0.15 × ATR` 开始验证，但该倍数不是已验证标准。定义最小跳动下限及相对波幅上限；无法同时满足时标记波段太小，不能无限放大区域。

把区域状态、价格反应和锚定结构有效性分开保存。典型转移：

```text
inactive → approaching → touched
                          ├─ reaction_confirmed → holding
                          └─ broken → retest → holding / broken
任一活跃状态 ──锚定结构失效──→ invalidated
```

这不是每次都必经的直线流程：跳空可以跳过触及，价格可以反复测试，反应后也可能破位。每次进入按 episode 去重；broken 表示该区域被有效穿越，invalidated 表示其锚定结构/使用条件失效。

上涨回撤跌穿 0.618 后，保留该事件并继续观察 0.786 和原始低点；不能自动判定会到达或守住下一比例。触及后出现小时 W、趋势线突破或规则定义的价格反应，才产生对应确认事件，触及本身不生成反转结论。

区域记录创建和评估时 ATR、容差版本。动态调整容差时不能把区域变宽算成价格主动进入；重设 A/B/C 生成新结构身份或明确版本关联，不改写旧区域事件。

### 9.3 多结构共振与波浪软指引

合并来源包括趋势线、通道上下轨、箱体边缘、前高前低、W/M 颈线、不同波段 Fibonacci 和可选均线。在同一时点、同一价格坐标中计算动态位置再聚类，限制聚类直径，避免链式合并成巨大区域。跨周期 ATR 不直接相加，指定主评估周期或统一相对距离。

例如“日线回撤 0.618 + 小时扩展 1.618 + 上升通道下轨”形成 Confluence Zone；保留原始来源。同锚点或同一条价格路径派生出的多个指标不能按独立证据反复加分。

将去重落实为 EvidenceFamily 与来源依赖分组：family 可包含 price_structure、trend_geometry、horizontal_level、fibonacci_same_swing、fibonacci_independent_swing、volume、higher_timeframe。family 是业务类别，并不自动证明统计独立。

每条证据保存 source_structure_ids、anchor_ids、derived_from 和 dependency_group。先把同 A/B、同投射、同一指标再包装的证据归组，再对家族设上限；嵌套但非完全相同的波段保留相关性折扣，不因周期不同就认定独立。higher_timeframe 若只是把同一条日线证据重新命名，也不能额外加分。

Confluence Score 输出去重前条目数、来源依赖组数、家族数、分项上限/折扣及最终得分；依据经去重的有效证据组贡献计算，不直接按画线数量或家族数量相加。例如“同一 A/B 的 0.618 + Wave 4 比例解释 + 另一指标包装的 0.618”只贡献一组位置证据。

波浪解释可使用比例作为 soft guideline：例如为第 2 浪配置较深回撤偏好、第 4 浪配置较浅回撤偏好、推动段配置扩展比例偏好。具体区间属于可测试参数；未命中 0.618 等比例不能单独使一个 WaveNode 非法。位置层不依赖波浪标签才能运行，也不因解释层重复使用同一比例而再次增加选股分。

### 9.4 Price Cluster 与研究用 Time Cluster

ConfluenceZone 显式保存 price_zone，并预留可空 time_window、duration_reference、time_ratio、research_only。time_window 是研究假设的时间范围，与对象有效期、as-of 和可用时间分开。

首版仅价格共振进入业务评分；time_window 默认 null。调整时长相对前段的 0.5/0.618 等只作为独立研究字段，不生成生产预警、加分或确认条件，不实施斐波那契时间周期推算。未来启用须单独样本外验证和版本化；未知 C 的持续时间只能标为正在增长的观测，不能借未来完成长度计算当时特征。

## 10. 多周期结构与长期递归波浪解释

日线/周线给出背景和主要关键区，小时线验证内部结构及触发。波浪级别不与固定时间周期绑定：周线、日线、小时线只是观测分辨率，不直接等价于 Primary、Intermediate、Minor。degree 由父子结构、相对幅度、持续时间和结构完整性共同决定，绝对命名无法判断时保留相对层级。

方向冲突保留并解释，例如“日线下降通道内，小时 W 突破”，不能直接升级成日线上涨反转。按真实时间区间关联父子结构；父级与子级须满足价格、时间和确认条件。缺失小时历史时标记内部细分未验证，不强制补出子浪。

### 10.1 长期锚点搜索与递归解析

波浪解释器读取指定版本的长期 Price Structure Tree，按以下流程执行：

1. 从可获得长期历史的粗尺度结构中寻找 major pivots，保留多个有依据的长期锚点。
2. 构造可能的父结构及分段方案，不先假设最近窗口就是一套完整推动浪。
3. 对父结构递归尝试子结构细分，按需展开 Segment 和更细数据；用规则有效性、内部覆盖和结构一致性判断。
4. 保留 Top-K 个合法或明确标记为部分验证的整树解释；已违反硬规则的解释淘汰并保留原因。未知分支不冒充完整合法 count。
5. 新数据更新受影响分支，并向祖先传播有效性与评分变化；若根锚点失效则允许更新整棵树，不局限于末端标签。

使用记忆化、共享只读子结构和确定性剪枝控制成本，记录搜索覆盖、剪枝原因和预算。Top-K、递归深度/节点预算限制计算，不代表不存在其他解释。预算不足返回 search_incomplete，区分数据不足、搜索未完成和规则不支持。

### 10.2 每个 hypothesis 是一整棵树

同一段 2019→2026 的行情，可以分别作为某一假设中的完整 1–5、另一假设的大级别第 3 浪、第三种假设的 ABC 中 C 段；这些只是可同时保留的解释示例，是否成立取决于各自父结构证据。父级证据不足时标记 parent_context_unknown。

每个 WaveHypothesis 必须包含根和父子关系、结构引用、相对 degree、起止/确认时间、各节点规则结果、整树状态、失效条件、匹配分拆解及 alternatives。失效条件可以是价格约束、父子结构矛盾或后续必须满足的规则，必须可执行检查；部分假设无法确定完整边界时明确返回未验证原因。

标准推动浪的硬规则与比例、时长偏好分开。违反硬规则不能靠其他加分恢复有效；未实现的复杂调整、倾斜三角形等返回 unsupported/unclassified，不硬贴 1–5 或 ABC。

允许候选 Zigzag、Impulse 及 Unclassified complex correction 并存。unknown/unclassified 不等于行情错误；rule_validity 可区分 valid、invalid、unverified，score 仅表示已评估规则的匹配程度，附覆盖情况，不能冒充上涨/下跌概率。

### 10.3 增量修订与历史不变性

当前浪可以多年延伸，无固定天数上限。新数据允许 relabel、延伸和重新选择主候选；修订保存父版本、时间、原因和依赖树版本。Parser 的修改只发生在解释记录，不能改动被引用的 Pivot/Leg/Segment。

固定输入数据版本、可用时间、配置、解析器版本、搜索预算及确定性排序规则时，追加未来行情后重放到过去 T，必须得到相同的 T 时候选快照。更早历史补齐或数据修正导致的新解释另存数据版本，不冒充当时已知。缓存与长期压缩同样只能使用 as-of 当时已确认的结构。

### 10.4 Wave Context 与交易触发分离

```text
Wave = Context：可能处于长期第 4 浪，存在另一套调整解释
Structure = Setup：通道下轨 + 方向性 Fibonacci 共振区 + 小时 W
Price action = Trigger：小时颈线闭合突破 / 回踩确认
```

波浪回答可能处于哪个长期阶段，结构与位置形成观察条件，具体价格事件触发选股状态或预警。关闭波浪解释器，趋势线、通道、W/M、Fibonacci 和预警仍须正常运行。每条输出分列 observed_structure、position_context、wave_hypotheses、trigger_evidence，避免将假设写成已发生事实。

## 11. 形态选股与排序

先完成结构识别，再按使用场景筛选：

| 池 | 进入条件 | 使用方式 |
|---|---|---|
| 观察候选池 | 有结构但未确认，或接近重要区域 | 观察后续触发 |
| 确认机会池 | 规则确认、数据完整度达标 | 查看位置、剩余空间和失效条件 |
| 风险池 | 触及压力、M 顶候选/破位、跌破支撑等 | 关注及持仓风险提醒 |
| 数据待补池 | 缺周期、历史短或来源异常 | 显示受限原因，不伪造低分 |

首期预设筛选场景：上升趋势线第三次确认、上升通道下轨反应、下降压力线突破及回踩、横向箱体突破、W 颈线突破/回踩、M 顶破位/反抽、斐波那契与结构共振区触及。

评分分项：结构质量、确认程度、关键位独立证据、跨周期一致性、量价证据、流动性与空间约束。缺数据使用明确缺失状态，不给假定中性分或虚构高周期分。

先设硬门槛，再排序；机会分与风险分分别输出。高危持仓不因机会分低被过滤。同标的多结构合并为一张卡片，保留全部证据及冲突。

分数只表示规则质量与排序；概率字段必须来自独立样本外校准，附样本量、期间和不确定性。Top 20 可作为展示默认值，不限制引擎保存全部结果。

波浪标签默认不作为硬筛选条件，仅提供长期结构背景、风险上下文和候选解释。未经独立样本外验证，不得因“当前为第 3 浪”直接增加机会概率或基础机会分。候选分数、位置共振、价格触发与波浪解释分别展示；未来启用经验证的上下文规则时，必须单独版本化并做消融对照。

## 12. 预警状态、去重与交付

### 12.1 事件定义

| 事件 | 依据 | 确认属性 |
|---|---|---|
| approaching | 进入外层接近区 | 提前提示 |
| touched | 报价/已知 K 线范围接触关键区 | 提前提示，不声称已经反转 |
| reaction_confirmed | 接触后满足止跌/受阻规则 | 规则确认 |
| crossed_intrabar | 未闭合周期穿越 | 盘中临时状态 |
| breakout / breakdown | 闭合周期满足越界规则 | 结构事件 |
| retest_hold / retest_reject | 突破后独立回测边界且确认 | 结构事件 |
| failed_break / invalidated | 返回区间或结构失效 | 风险事件 |
| feed_stale / coverage_lost | 数据陈旧或覆盖不足 | 系统事件 |

数据只支持小时闭合检查时，不宣称分钟级即时触及。报价跳跃越过整段区域时报告跳过/穿越，不虚构中间实际成交。只知道一根 K 线高低范围时，事件时间使用已知边界，不能编造精确触碰顺序。

### 12.2 去重与重启

- 去重主键包含订阅、标的、周期、结构/区域 ID、事件类型和本轮触碰 episode。
- 进入区域只提醒一次；退出更宽的复位边界并达到冷却条件后才允许新一轮，防止边缘抖动。
- approaching 升级成 breakdown 可再次提醒；冷却不能吞掉新的结构失效事件。
- 同时触发的多个重叠证据聚合为一条通知；保留每个来源。
- 行情消费水位、事件写入、通知 outbox 在事务边界内处理，重启后恢复；本地事件幂等。
- 外部投递按至少一次及幂等键设计；不能承诺第三方渠道绝对恰好一次。记录回执、不确定结果、重试和死信。
- acknowledged/muted 属于用户处理状态，与形态是否失效分开。

### 12.3 消息与运行

通知必须包含：标的、周期、事件、实际数据时间、当前价/关键区、接近方向、确认属性、证据、失效条件和图表入口。支持按类型、周期、级别、标的池、安静时间配置。

优先实现本地收件箱与桌面展示适配。邮件/webhook 等为可选适配器，实施时配置渠道和凭据后启用；本计划不创建任何外部订阅。

监控进程与 stdio MCP 解耦；CLI worker 或系统任务驱动轮询。限定交易时段，闭市后执行归档。加入单实例租约、心跳、重试、限流、优雅退出和断线恢复。

## 14. 回测与验证

### 14.1 三种验证分开

1. 结构识别：人工标注样本与合成样本验证是否识别正确、何时确认、是否存在未来信息。
2. 预警事件研究：按预先定义的期限与价格反应阈值评估触及后的反应、假突破、提前量、重复率和漏报。
3. 交易模拟：明确进出场、仓位、成交成本、市场制度与可交易性，评估实际组合结果。

预警及时不代表交易盈利；形态匹配好也不代表收益高，各自报告指标。

### 14.2 因果与数据约束

- 逐根回放共享实盘引擎，任何信号只能使用当时已到达的数据和已确认拐点。
- 固定数据/规则版本，对前缀运行与完整数据回放比较：时间 T 前已经发出的事件必须一致。
- 未来追加数据可改变最新候选解释，但不能改写过去的确认和预警。
- 同一结构多次触碰按 episode 分组；训练测试按时间切分，对重叠结果窗口设置隔离，避免泄漏。
- 市场名单、上市退市状态、复权因子和板块成员若无历史快照，明确披露幸存者与样本选择限制。
- 缺少历史小时数据时仅验证可覆盖期间，不声称具备长期小时回测。
- 波浪验证固定数据可用时间、Parser 版本、计算预算和确定性候选排序；比较压缩/展开路径及批量/增量路径的候选树引用和有效性，未知分支单列。
- 追加更晚行情、补齐更早历史、修正已有数据是三种不同测试；前者不得改变旧 as-of 输出，后两者创建新数据版本并保留原在线快照。

### 14.3 成交模拟改造

- 按标的和日期读取适用的交易约束，例如持有期限、涨跌幅限制、停牌和最小交易单位；规则在实现阶段核实并版本化。
- 下一根可交易 K 线才处理确认后入场；小时信号不能绕过适用的当日卖出约束。
- 跳空越过止损按可成交价格估算，锁住无法成交则延迟；不假定总能按止损价成交。
- 同根同时碰止盈止损时，使用可得低周期数据或明确的保守规则，报告其影响。
- 同时评估结构失效退出、目标位退出、时间退出；固定 2R 仅作为一个基准方案。
- 组合按完整交易日序列逐日估值，含未平仓持仓、现金、成本和空仓日；据此计算回撤和风险指标。
- 与简单基准、旧引擎和去掉某项证据的版本比较，检验复杂规则的增量价值。

不预设盈利验收目标。最优参数只有通过样本外与稳定性检查后才进入候选发布配置，不自动覆盖线上规则。

### 16.1 P3 位置层专项验收

1. Retracement 无 C 可计算，Projection 缺 C 拒绝计算；provisional C 不冒充确认端点，current_price 不覆盖 C。
2. A=10/B=20/C=15/P=21 的回撤、A 基准位置、C 基准投射分别为 -0.1、1.1、0.6；上涨/下跌镜像与零幅波段测试通过。
3. phase 依赖历史路径和确认规则；区分恢复、过度回撤、盘中待确认以及新一轮调整，不能仅按 ratio 改状态。
4. 同行情保留多尺度锚点；排序可复现，换锚保留旧事件，有效旧区域不会因新局部高点出现而一律消失。
5. 相同 A/B 的比例位、Wave 指引与指标包装不重复加分；同锚点 measured move 与 1.0 投射去重，跨家族共享来源也受限。
6. Wave 开关和 relabel 不改变锚点资格/排序、Fib 区域及基础 Confluence Score；只改变解释输出。
7. 独立 Projection 在未运行 Fibonacci/Wave 时可生成等幅目标；目标与已完成等幅运动状态分开。
8. research_only 的 time_window/time_ratio 改变，不影响生产排名、触发和通知；不可使用未来最终持续时间。
9. phase、zone 状态、anchor 有效性与时间字段分别序列化并可回放，未知或预算不足显式披露。

### 16.2 P8a 波浪专项验收

1. 同一行情允许多个合法 count，各自是完整树假设；有多个可行解释的测试样本不得被接口强制压成唯一标签。
2. 每个 count 有明确 parent/child、结构引用和相对 degree，父子区间/方向约束可核验；根或外部父级未知要显式标记。
3. 每个可验证 count 有可检查的 invalidation condition；尚不足以形成完整约束的候选标记 unverified，不冒充合法已确认解释。
4. 新数据允许 relabel、延伸或淘汰，并能显示具体原因及受影响分支。
5. relabel 不覆盖历史 snapshot，也不修改其引用的底层价格结构。
6. 固定输入版本、可用时间及解析配置时，追加未来数据不得改变过去 as-of 的候选输出；历史补齐/修订另建版本。
7. degree 不与 timeframe 强绑定，测试同一分辨率存在多个级别、同一结构引用多个分辨率的情况。
8. 长期分析不受固定 320/500/1000 根窗口限制；跨多年样本能保留早期锚点，分页预算中断可恢复，并披露历史/搜索未完成状态。
9. 无法合法分类时必须允许 unknown/unclassified；数据不足、规则不支持和明确违规可区分，不能被强制贴成 1–5/ABC。
10. 输出 score 只称匹配分并附规则覆盖，不能称为上涨/下跌概率；波浪关闭或未知不阻断结构预警。

另做架构一致性检查：Parser 无底层结构写权限；增量和同预算确定性重算的结果一致；缓存只复用同数据/规则版本；父级失效能传播到依赖子树。Fibonacci 软比例不满足时不能单独判定浪型非法。

## 17. 必测场景与发布门槛

| 类别 | 验证样本 |
|---|---|
| 趋势线 | 仅两点、第三点尚未确认、重复贴线、影线穿越、收盘破位、角色转换 |

发布门槛：

- 所有因果性、身份稳定性、幂等、确认时间测试必须通过。
- 确定性回放与增量处理在固定输入和配置下输出一致。
- 任意一条用户可见结果都能回溯锚点、当时数据与规则版本。
- 每个核心形态家族先整理不少于 20 个覆盖正例、反例和模糊例的人工检查样本；该数量是初始验收集，不足以证明统计有效性。
- 预警监控在目标机器上完成至少 10 个交易日影子运行，核验漏报、重复、升级和恢复；每次严重错误修复后补相关回放。
- 性能目标在 P1 测量目标机器和数据规模后冻结；基本要求是增量处理小于调度间隔，通知延迟预算明确，任务不重叠堆积。
- 任何收益统计注明数据覆盖、样本期间、交易约束与偏差；样本不足时不输出确定的胜率结论。

## 18. 配置、运维与最终交付

配置分三组：识别规则（尺度、触点容差、确认/失效）、筛选偏好（周期、方向、流动性、数量）、监控策略（订阅池、频率、冷却、通知）。配置有 schema、默认值、版本和变更记录；ATR 倍数及时间阈值初期都是待验证参数。

位置层配置明确锚点资格/排序、每尺度保留数、换锚及退役规则、Projection 比例、phase 转移、区域容差、证据家族上限与依赖折扣。时间共振研究配置独立且默认关闭生产影响。

波浪解释配置独立于三组业务配置：长期历史策略、Parser 规则版本、Top-K、递归/节点预算、软指引权重、确定性排序及缓存策略。调整解释配置不得隐式改变观测结构与预警规则；解释版本变化单独记录。

运行指标：数据新鲜度、各周期覆盖、接口失败率、扫描耗时、队列积压、事件数、去重数、投递失败、最后成功运行。数据问题与技术形态风险分开显示。

日志写 stderr 或专用文件，不能污染 MCP stdio；凭据从环境或受控配置读取，日志脱敏。清理策略区分行情缓存、派生缓存和审计证据。故障可暂停投递、保留采集与事件，恢复后按有效时限处理积压，避免把旧提醒当成当前提醒。

最终交付清单：

- 数据迁移、小时历史维护与覆盖报告。
- 统一 Pivot/Leg/Segment/长期结构树、趋势线、三类通道、W/M、方向性 Fibonacci 区域。
- 独立 Projection/Measured Move、锚点选择与运动阶段、可审计 EvidenceFamily 去重及 P3 专项验收报告。
- 多周期选股、关键位与风险池、可解释评分。
- 持久预警状态、本地收件箱、后台 worker 与恢复机制。
- 同源结构图、个股证据包、兼容 MCP/CLI 与说明文档。
- 回放/回测工具、标注样本、样本外报告及试运行记录。
- 长期递归 WaveHypothesis、只读 Elliott Parser、增量修订与专项验收报告，以及管理页面。
